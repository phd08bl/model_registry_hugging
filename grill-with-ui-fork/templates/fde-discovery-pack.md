# MRO FDE Discovery Pack

## 1. Discovery Executive Summary

Summarise:

- the process/problem examined;
- the Stage 2 discovery question;
- the most important findings;
- the opportunities identified;
- the recommended Gate 3 outcome.

Do not describe a solution as approved unless it has actually been approved.


## 2. Stage 2 Context and Discovery Scope

Include:

- Candidate Brief summary;
- Process Owner;
- Desired Outcome;
- SLT / Leadership priority;
- Stage 2 decision;
- Discovery Question;
- Initial Discovery Wave;
- in-scope boundary;
- out-of-scope boundary.


## 3. Current-State Process

Include:

- purpose;
- trigger;
- completion;
- main process;
- subprocesses;
- genuine variants;
- key exceptions.


## 4. People, Handoffs, Judgement & Controls

Include:

- roles;
- handoffs;
- approvals;
- human judgement;
- controls;
- escalations;
- waiting/rework.


## 5. Systems, Data & Existing Initiatives

Include:

- relevant systems;
- authoritative sources;
- access / interfaces;
- traceability / data-quality issues;
- restrictions;
- existing tools / PoCs / initiatives.


## 6. Representative Real-Case Walkthrough

Describe the representative case(s) reviewed and what was learned.

If none were available, state the limitation.


## 7. Evidence Register

Use a table containing at least:

Evidence ID
Evidence Type
Source
Evidence
Supports
Process Step
Status
Owner / Date where known


## 8. Baseline & Materiality

Describe available baseline, scale, frequency, impact and materiality.

Clearly distinguish measured values from stakeholder estimates.


## 9. Pain Points & Root Causes

For each material pain point include:

- process location;
- affected users;
- scale;
- impact;
- evidence;
- root cause;
- symptom vs root-cause assessment;
- workaround;
- desired improvement.


## 10. Key FDE Findings

List F01, F02...

For every material finding show:

- finding;
- supporting Evidence IDs;
- confidence;
- evidence gap where relevant.


## 11. Improvement Opportunity Map

Show how findings translate into opportunities.

For example:

F01 + F03 → O01
F04 → O02

Do not select technology prematurely.


## 12. Improvement Opportunity Cards

Include a complete Opportunity Card for every material opportunity being
considered for progression.


## 13. Common-vs-Variant / Reuse Assessment

Summarise:

- local process elements;
- potentially common elements;
- clearly common elements;
- unknown areas;
- reuse rationale.


## 14. Process Owner Playback

Record the current-state summary and Process Owner confirmation status.


## 15. Open Questions & Dependencies

Include only material unresolved points.

Identify what would resolve them and whether they block Stage 4.


## 16. Gate 3 Recommendations

Give the recommendation per material opportunity and evidence basis.


## 17. Next Discovery Wave

Where relevant, identify what should be investigated later rather than expanding
the current scope indefinitely.


## 18. Stage 4 Handover

For each opportunity progressing to Stage 4 include:

Selected Opportunity
Problem sufficiently understood: YES / PARTIAL / NO
Evidence sufficient: YES / PARTIAL / NO
Baseline: ESTABLISHED / PARTIAL / NOT AVAILABLE
Existing capabilities considered: YES / NO
Non-technology option considered: YES / NO
Non-AI options considered: YES / NO
Key constraints understood: YES / PARTIAL / NO
Supporting Findings
Supporting Evidence
Open Questions
Recommended Direction
Solution Selected: NO
Stage 4 Question

"Solution Selected" should normally remain NO because detailed solution
selection belongs to Stage 4.
